# ZoomPlus

A lightweight and customizable zoom mod for Minecraft Java Edition.

## Features

- Smooth zoom animations
- Custom zoom levels
- Hold and Toggle zoom modes
- Scroll wheel zoom
- Double-tap maximum zoom
- Custom animation speed and easing
- Camera and visual options
- Customizable controls
- In-game settings menu

## Compatibility

- Minecraft: 1.21.11
- Mod Loader: Fabric
- Fabric API: Required

## Default Controls

| Action | Key |
|---|---|
| Zoom | `C` |
| Reset Zoom | `R` |

Keys can be changed from Minecraft's Controls menu.
